# TooltipLootRollStats

WoW: Forever 客户端插件。鼠标指向玩家时，在单位提示框末尾加一行他的「需求 / 贪婪」掷骰次数：

```
需求: 128次  贪婪: 342次 (updated:2026-11-14 13:40)
```

数据取自成就统计，通过成就比较接口向服务器查询，按角色 GUID 缓存在 `TooltipLootRollStatsDB`。

- 1044 = 需求掷骰次数
- 1043 = 贪婪掷骰次数

## 用法

装上即用，没有设置界面。光标在玩家身上停留 0.6 秒后开始查询，数据回来时如果提示框还停在这个人身上，会立刻刷新；查不到的显示：

```
需求: -  贪婪: -
```

命令：

| 命令 | 作用 |
| --- | --- |
| `/tlrs` | 查看缓存条数 |
| `/tlrs clear` | 清空缓存 |
| `/tlrs target` | 立即查询当前目标 |
| `/tlrs self` | 打印自己的两项次数 |
| `/tlrs debug` | 开关调试输出，聊天框会打印每次查询的单位与读数 |

## 缓存规则

- 按 GUID 存，同一条记录 24 小时内不重复查询，过期后在你再次悬停时后台刷新。
- 查询失败（超时、对方不可观察）不写缓存，同一个人 5 分钟内不重试。
- 同一时间只跑一个查询；扫过一群玩家时只有停留足够久的那个会被查。
- 记录超过 180 天、或总数超过 2000 条时自动清理。

## 已知限制

- 只能读到客户端允许观察的玩家。距离过远、跨阵营、副本相位不同等情况会一直显示 `-`。
- 同一时间只能比较一个玩家，快速从一个玩家移到另一个玩家时，后一个要排队等前一个结束或超时。
- 数字是客户端成就统计里的累计值，插件不做任何推算或补充。

## 安装

游戏目录里的 `Interface\AddOns\TooltipLootRollStats` 是指向本仓库的 junction，改完代码 `/reload` 即可生效。

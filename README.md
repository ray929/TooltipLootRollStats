# TooltipLootRollStats

WoW: Forever 客户端插件。鼠标指向玩家时，在单位提示框末尾加两行：他的「需求 / 贪婪」掷骰次数，以及一行字号更小的数据时间：

```
需求: 128次  贪婪: 342次
(updated:2026-11-14 13:40)
```

数据取自成就统计，通过成就比较接口向服务器查询，按角色 GUID 缓存在 `TooltipLootRollStatsDB`。

- 1044 = 需求掷骰次数
- 1043 = 贪婪掷骰次数

## 用法

装上即用，没有设置界面。光标在玩家身上停留 0.6 秒后开始查询，数据回来时如果提示框还停在这个人身上，会立刻刷新；查不到的显示：

```
需求: -  贪婪: -
```

### 语言

文案有简体中文、繁体中文、英语三套。客户端是简中或繁中就用对应中文，其它语言（含英语客户端）一律英语。要固定某一种，用 `/tlrs lang`：

| 取值 | 效果 |
| --- | --- |
| `auto` | 跟随客户端（默认） |
| `zhCN` | 强制简体中文 |
| `zhTW` | 强制繁体中文 |
| `enUS` | 强制英语 |

设置存在存档里，立即生效，不用重载。`/tlrs lang` 不带参数时显示当前设置。

### 命令

| 命令 | 作用 |
| --- | --- |
| `/tlrs` | 查看缓存条数 |
| `/tlrs clear` | 清空缓存 |
| `/tlrs target` | 立即查询当前目标 |
| `/tlrs self` | 打印自己的两项次数 |
| `/tlrs debug` | 开关调试输出，聊天框会打印每次查询的单位与读数 |
| `/tlrs lang` | 查看或切换语言 |

## 缓存规则

- 存档是账号级的（`## SavedVariables`，不是 `PerCharacter`）：文件在 `WTF\Account\<账号>\SavedVariables\TooltipLootRollStats.lua`，同一 WoW 账号下所有角色共用一份缓存，任一角色执行 `/tlrs clear` 都会清掉全部。
- 按 GUID 存，同一条记录 24 小时内不重复查询，过期后在你再次悬停时后台刷新。
- 查询失败（超时、对方不可观察）不写缓存，同一个人 5 分钟内不重试。
- 同一时间只跑一个查询；扫过一群玩家时只有停留足够久的那个会被查。
- 记录超过 180 天、或总数超过 2000 条时自动清理。

## 已知限制

- 只能读到客户端允许观察的玩家。距离过远、跨阵营、副本相位不同等情况会一直显示 `-`。
- 同一时间只能比较一个玩家，快速从一个玩家移到另一个玩家时，后一个要排队等前一个结束或超时。
- 提示框一行只能有一种字号，所以更新时间单独占一行；换行后的字号按该行原来的字号减 2 点。
- 数字是客户端成就统计里的累计值，插件不做任何推算或补充。

## 安装

游戏目录里的 `Interface\AddOns\TooltipLootRollStats` 是指向本仓库的 junction，改完代码 `/reload` 即可生效。

版本号由 CurseForge 打包器按 tag 写进 toc（`@project-version@`），本地直接链接这份源码时，插件列表里显示的就是这串占位符，属正常现象。
